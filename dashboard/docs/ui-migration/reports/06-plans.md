### Oportunidades de redesenho (3-6 bullets)
- **Header do detalhe = breadcrumb + h1 + status pill + ações no console**: "plans / test plan", pill `comparison ready · locked`, e no header do console "run candidate" (primary) / "view baseline" (quiet). Some o card de readiness, o pill lateral e o footer.
- **Três blocos claros**: (1) *Scope* — testes como chips, runs, modelo, juiz, seed; (2) *Runs* — timeline baseline → candidate 1 → candidate 2 (data, resultado, tokens, duração, verdict), com rename e "report" por item, substituindo as duas listas atuais das mesmas execuções (tabela de comparação + "Execution history" repetem cada id 2-3×); (3) *Compare* — baseline vs candidato selecionado (só métricas reportadas, objetivas primeiro), com link "open in Compare" (`hashForComparison`, `hooks/use-hash-route.ts:119`) para a comparação completa.
- **Running como estado de primeira classe**: banner no topo com progresso n/m, tempo decorrido, "view live" e "cancel"; polling sem flicker.
- **Draft editável de verdade**: "edit scope" reabre o formulário de `plans/new` com o draft; "discard" com confirmação; "archive" para planos concluídos.
- **Mobile**: abaixo de 840px a comparação vira cards por candidato; a tabela só em ≥ 840px.
