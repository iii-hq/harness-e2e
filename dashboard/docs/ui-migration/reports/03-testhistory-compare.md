### Oportunidades de redesenho (3-6 bullets)
- **"Comparison builder" no topo**: stepper horizontal cohort → A → B com cards ricos de versão (data, revisão curta, N execuções, "k tests comparable with B") e uma lista de "pares recomendados" em vez de heurística silenciosa; o cabeçalho passa a mostrar KPIs (comparable / regressed / improved / one-sided).
- **Tabela por estado**: seções "Comparable (n)", "Evidence on one side (n)", "No evidence (n, colapsado)"; uma linha por lado; Δ com seta e cor para score, custo e duração; `thead` sticky; paginação/virtualização.
- **Fundir com o catálogo**: o catálogo já lista os mesmos 47 testes com "View metrics"; a Compare pode ser um modo do catálogo ("compare systems" adiciona as colunas A/B e Δ), eliminando a segunda lista e a segunda busca.
- **Expansão da linha → Test history com A/B pré-selecionados** (`tests/<id>?a=<exec>&b=<exec>`) em vez de reimplementar uma lista de evidência dentro da tabela.
- **Substituir o chrome legado** (eyebrow + live-dot, sync-block, footer, ambient) pelos primitivos de página do DS, alinhando fonte, raio e preenchimento com Overview/Executions.
