### Oportunidades de redesenho
- **Editor de duas colunas com preview vivo**: formulário à esquerda, Markdown gerado à direita sempre visível em ≥ `lg` (rolagem própria, botão copy), rodapé fixo com medidor de peso (barra segmentada por critério) e Create/Cancel. Vale um mockup.
- **Modo "Markdown" alternativo**: como o arquivo é a fonte de verdade (`buildLocalScenarioSource`, authoring.ts:217-237), oferecer toggle "Form / Markdown" com o template pré-carregado e o mesmo parser (`parseLocalScenarioSource`) validando ao digitar — hoje só existe upload.
- **Critérios como linhas compactas** (nome | peso | instruções expansíveis) com soma ao vivo e "distribute evenly", em vez de três cartões bordados de 260px cada.
- **Fluxo pós-criação**: fechar o diálogo → linha nova destacada + toast com "view history" e "create plan"; opcionalmente "create and open plan" como ação secundária do próprio diálogo.

### Quick wins
- `placeholder` em vez de `value` no rascunho inicial; file name sugerido = slug do título, sem "local-".
- `<small className="text-xs">` no help de file name (9,6px → 12px) e `text-xs` no `<pre>`; ghost → faint nas descrições.
- Rodapé fixo com Create/Cancel (`grid-rows-[auto_1fr_auto]`) — CSS apenas.
- `rounded-[6px]` no diálogo, inputs, botões e fieldsets; remover `border` dos inputs em favor de `bg-[var(--surface-fill)]`.
- `max=100` + `inputMode="numeric"` em Weight e Version.
- `title="import .md"` no botão de import quando o texto está `sr-only`.
- Toast com link após criar; remover o status persistente.
- Confirmar descarte reutilizando o `harness-e2e-discard-dialog` de LocalPlanPage.
