# PR B · ui/plans-and-setup — plans list, plan detail, shared setup sheet

Branch `ui/plans-and-setup` · base main (after A merges) · depends on A ui/foundation · size 1–2 weeks.

Read `docs/ui-migration/README.md` first: it holds the rules every UI PR follows and the verification recipe. This brief lists what this PR closes; the audit reports (`docs/ui-migration/reports/`) hold the full finding text and the screenshots each one cites.

## Scope

Three surfaces, in this order:

1. **Plans list** (`pages/PlansPage.tsx`) — tabular list on `DataTable`: one row per plan, one action per state, deltas inline with `DeltaValue`, `FilterChip` filters, "how plans work" only in the empty state. "regressions" is red only when > 0, "In progress" reads "running", footers and the live-dot go.
2. **Plan detail** (`pages/LocalPlanPage.tsx`, detail page) — breadcrumb + a single status + actions at the top; `PlanLifecycle` before the comparison; inline confirmation before running; scope as chips listing `plan.scenarios`; run timeline; comparison only with reported metrics; edit/discard draft, archive; stacks at ≤ 840px.
3. **Setup sheet** (`components/ExecutionSetup.tsx`, `LocalRunnerDialog.tsx`, plan creation) — one-column `Sheet` with a fixed footer, scope grouped in 36px rows with a search that stays put, model combobox, quick/plan mode inside the component; serves the Overview dialog, `plans/new` and "quick execution".
