# Evolução de versões do Harness

A estratégia de evolução foi incorporada ao
[plano mestre de testes e medição](e2e-test-plans.md), que define o perfil
`evolution`, sua cobertura, métricas, identidade, amostragem e qualificação.

O [rascunho anterior está preservado como histórico](version-evolution-2026-09-05.archive.md).
Suas observações locais não foram revalidadas; ele não define o plano vigente.
Os manifests e o script experimental locais permanecem preservados. A geração
executável dos novos perfis é uma etapa proposta no plano mestre.
